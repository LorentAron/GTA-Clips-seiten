Privacy Policy

GTA Clips Uploader · Last updated: 19 November 2026

1. Summary

GTA Clips Uploader is a private tool that only publishes clips to the operator's own accounts. It collects as little data as possible and never sells or shares data with third parties.

2. Data the tool receives

  • TikTok: an access token and refresh token after you sign in, basic profile information (user.info.basic: open ID, display name, avatar) and the information TikTok returns when creating a post (for example the allowed privacy levels and the publish status).
  • YouTube: an OAuth refresh token and the IDs of uploaded videos.

The tool does not access your followers, messages, contacts, location, viewing history or any other content.

3. How the data is used

The data is used only to upload the operator's own video clips at the scheduled times and to record whether an upload succeeded.

4. Storage and security

Tokens are stored as protected secrets in the operator's private cloud environment and are never written to the public source code or to logs (secrets are masked). A small local database stores only file names, scheduled times, upload status and the resulting post IDs or links.

5. Sharing

Data is sent only to TikTok and Google/YouTube through their official APIs in order to publish the clips. It is not shared with, sold to or used by anyone else, and it is not used for advertising or profiling.

6. Retention and deletion

Tokens are kept until access is revoked or the tool is no longer used, then deleted. You can revoke access at any time in the TikTok app (Settings and privacy → Security → Apps and services) and at myaccount.google.com/permissions; revoked tokens stop working immediately.

7. Children

The tool is not directed at children and is used only by its adult operator.

8. Changes and contact

This policy may be updated; the date above shows the latest version. Questions can be raised via the project page: github.com/LorentAron/GTA-Clips.
